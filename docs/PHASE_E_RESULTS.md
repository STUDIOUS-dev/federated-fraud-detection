Mechanism: each client update (local − global) is clipped to L2 norm C = 0.5, the server averages clipped updates with equal weights and adds Gaussian noise with std z·C/m (m = participating banks). ε is client-level (protects a whole bank's contribution), from zCDP composition over all rounds with no amplification claimed. With only 4 clients, the noise per coordinate is large relative to the averaged signal; real deployments use hundreds of clients for this reason.

Threat model: the attackers are omniscient and colluding. In each round they see all honest updates and send one identical crafted update (the standard setting in which ALIE and Min-Max are evaluated). `alie`: mean − z·std per coordinate (z = 1 or 3; the paper's formula gives z = 0 for 4 clients). `minmax`: mean + γ·(−std/‖std‖) with the largest γ that keeps the update no farther from any honest update than the honest updates are from each other.
